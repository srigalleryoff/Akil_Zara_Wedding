GITHUB PAGES DEPLOYMENT:
1. Extract this ZIP.
2. Upload index.html, README.txt and the complete assets folder to the ROOT of your GitHub repository.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish and copy the website URL shown there.
